PART 6 -- IS THIS A "PHASE 1 ONLY CATCHES 100% INFEASIBILITY"
LIMITATION? (calculated, not speculated)
=====================================================

[FACT] Yes -- this is exactly the mechanism, and it is fully disclosed,
documented Phase 1 scope (implementation report Section 11: "no
`max_attempts`-aware risk projection was built" for anything short of
proven 100%).

Calculation (using the actual reproduction's real numbers, Part 3/4,
not a hypothetical): let p = lethal_fire_probability = 0.99667 (the
per-ATTEMPT probability that a randomly sampled fire zone disconnects
the occupied zone, computed analytically and confirmed exactly matching
the empirical run).
  P(one scenario slot exhausts max_attempts=10) = p^10 = 0.9670
  P(ALL 10 requested slots exhaust, i.e. the exact "0 accepted /
    10 rejected / 100 total attempts" outcome) = (p^10)^10 = 0.7161
    (71.6%)
This is NOT a rare fluke -- it is the MORE LIKELY outcome (71.6% vs
28.4%) for this exact configuration. A second, independent run (a
smaller N=59 reproduction, p=0.9831) gave P(all 10 exhaust)=18.1%
predicted, and the actual run observed 8/10 slots exhausted (matching
its own, lower, predicted single-slot-exhaustion rate of 84.3% almost
exactly: 8/10=80% observed vs 84.3% predicted). Both reproductions'
predicted probabilities and observed outcomes are statistically
consistent with each other, using ONLY the Definition's own real
weights -- not speculation.

[FACT] `report.has_errors` was False in both reproductions (confirmed
directly) -- Phase 1 correctly refused to claim a PROOF of zero
feasibility it did not have (the space is not exactly 0% -- one
zone-safe fire draw, or a favorable door/exit/stair combination for the
"uncertain middle" not yet analyzed by Phase 1, could in principle
still succeed), and instead reported the WARNING with the exact
quantified risk. This is Phase 1 functioning exactly as its own
documented Case 3 ("optimistic reachable, some fire zones LETHAL
without reaching 100%") specifies -- not a bug.

Verdict for Part 6: CONFIRMED as the operative mechanism, by
calculation against the real Definition weights and cross-checked
against an actual executed campaign's real outcome, not speculation.
